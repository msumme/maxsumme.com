"We would make this easier to test, but it would complicate the code"

This is why your code is so complicated. If it's hard to test, it won't get easier to test, and change won't happen when it needs to.

Easy to change means easy to refactor means easy to update into an intelligible whole as your domain and product evolve.

If you don't make testing the first thing you solve, then you'll be forever solving testing AND all of the other problems that compound due to a poor testing story.

Easy to test means you do test. If you do test, you can change. If you can change, you can win.
